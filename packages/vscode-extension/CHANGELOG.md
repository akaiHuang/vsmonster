## [0.0.1] - 2026-01-30

### 🎉 Initial Release

#### Added
- **Gateway Connection**: WebSocket connection to VSMONSTER Gateway
- **Task View**: Visual task list in sidebar
- **Channel Status**: Monitor connected social platforms
- **MCP Services**: View and manage MCP servers
- **Commands**:
  - Connect/Disconnect Gateway
  - Show connection status
  - Start Gateway in terminal
  - Run setup wizard
  - Open quick start guide
- **Settings**:
  - Gateway URL configuration
  - Auto-connect on startup
  - Notification preferences
  - Default AI model selection
- **Copilot Integration**: Bridge for forwarding messages to Copilot

#### Supported Platforms
- LINE
- Telegram
- Discord
